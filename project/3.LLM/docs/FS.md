### 📝 기능명세서 (Functional Specification)

* **프로젝트명:** 3차 프로젝트 - 법률 용어 풀이 및 요약 AI 챗봇

| 구분 | 기능명 | ID | 세부 동작 및 로직 |
| :--- | :--- | :--- | :--- |
| **프론트엔드** | 법률 원문 입력 화면 | FR-01 | 메인 페이지 중앙에 법률 문서를 입력할 수 있는 텍스트 영역(textarea)을 배치하며, "풀이할 법률 문서를 입력하세요"라는 안내 문구를 띄워둠 |
| **프론트엔드** | 글자 수 제한 및 제어 | FR-01 | 텍스트 입력은 최대 1,000자까지로 제한하고 우측 하단에 실시간 글자 수를 표시, 초과 입력 시 키보드 입력을 차단하고 화면에 토스트 메시지 형태의 팝업 이벤트 출력 |
| **프론트엔드** | 요약 요청 및 로딩 | FR-02 | 입력창이 비어있을 때 버튼 클릭 시 경고창을 띄우고, 내용이 있으면 서버 요청 후 응답 전까지 로딩 애니메이션을 띄우며 대기 중 버튼 중복 클릭을 방지 |
| **프론트엔드** | 결과 출력 및 면책 조항 | FR-04 | 요약 결과 출력 시 하단에 "본 답변은 AI가 작성한 참고용이며, 실제 법적 효력을 갖지 않습니다. 정확한 판단은 법률 전문가와 상담하십시오."라는 문구를 강제로 노출 |
| **백엔드** | 데이터 수신 | FR-02 | 1차 프로젝트 화면(프론트엔드)에서 입력된 데이터를 REST API 방식을 통해 JSON 형태로 Flask 서버에 전송받아 파싱 |
| **백엔드** | AI 추론 및 결과 반환 | FR-03 | 전달받은 텍스트를 파인튜닝된 LLaMa 3.2 3B 모델에 통과시켜 요약본을 생성하고, 완료되면 다시 JSON 형태로 프론트엔드에 반환 |
| **백엔드** | 예외 및 오류 처리 | NFR-02 | 목표 시간 초과 시 프론트엔드에 408 에러 코드를 반환, 서버 내부에 문제가 생기면 500 에러 코드를 반환하고 시스템 장애 메시지 노출 |
