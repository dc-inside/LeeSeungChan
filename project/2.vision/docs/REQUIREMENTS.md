📝 요구사항 분석서 (Requirements Analysis Document) 

📌 1. 프로젝트 개요 

공사 현장에서 발생할 수 있는 안전사고를 미연에 방지하기 위해, CCTV 및 영상 데이터 내 작업자의 안전모 및 안전조끼 착용 여부를 실시간으로 판별하는 비전 AI 객체 탐지(Object Detection) 시스템 구축.

웹 프론트엔드의 접근성과 Linux 환경의 고성능 AI 연산 능력을 모두 확보하기 위해 윈도우 Flask 서버(관문 및 UI)와 로컬 WSL2 Flask 서버(YOLOv8 추론 엔진)를 분리한 3계층(3-Tier) 아키텍처를 채택하였으며, 대용량 비디오 처리를 위해 RESTful API 기반(HTTP POST) 파이프라인을 구축함.

---

👥 2. 사용자 유형 

**현장 안전 관리자(Safety Manager):** 공사 현장 관제 화면이나 현장 촬영 영상을 웹 인터페이스에 업로드하여, 작업자들의 안전 장비(안전모, 안전조끼) 미착용 위반 사례를 실시간으로 모니터링하고 즉각적인 안전 조치를 취하고자 하는 실무 사용자.

📊 5. 데이터 요구사항 (Data Requirements) 
 
**포맷:** YOLOv8의 엔진 및 지도 파일(`data.yaml`) 구조에 완벽하게 자동 매칭되도록 이미지 파일과 1:1 매핑되는 바운딩 박스 좌표 기반의 YOLO 포맷(.txt)을 준수

**내용 구성:**
**정답 클래스(3가지):** `0: Head` (안전모 미착용 맨머리/위반 사례), `1: Helmet` (안전모 착용), `2: Vest` (안전조끼 착용)

**배경 데이터(Negative Samples):** 구조물만 존재하고 사람이 전혀 등장하지 않는 공사장 풍경 전경, 파이프, 건설 자재 등의 프레임을 전체 데이터셋의 **5% ~ 10%** 를 의도적으로 섞어 정답지가 비어있는 '빈 텍스트 파일(.txt)'로 빌드하여 모델의 오탐 성능을 교정

**데이터 출처 및 수집 전략:** Pexels에서 고품질 현장 영상을 다각 구도로 확보
동영상을 원본 프레임(30fps) 그대로 사용 시 과적합이 발생하므로 OpenCV를 통해 **1초당 1프레임(1 FPS)** 간격으로 유니크한 프레임을 샘플링하여 추출

🚫 6. 제약사항 (Constraints) 

**하드웨어 및 인프라 리소스 한계:** 로컬 데스크톱 및 노트북의 Linux WSL2 환경 내부에서 PyTorch 및 CUDA 가속 가상환경(venv)을 빌드하여 YOLOv8 모델 학습 및 백엔드 추론 연산을 전담하도록 제한

**REST API 동기식 통신의 한계:** 오랜 대기가 발생하는 긴 동영상 처리 시 HTTP 타임아웃 에러를 유발하므로, 단순한 구조를 유지하기 위해 웹 서비스에 입력할 수 있는 사용자 비디오 파일의 길이를 "5~10초 분량의 단건 클립"으로 엄격히 제한

**비디오 인코딩 호환성 제약:** WSL2 리눅스 환경과 윈도우 환경 간 OpenCV 영상 프레임 재합성 시 코덱 호환 문제로 `.mp4` 요청이 내부적으로 `.avi` 형태로 유실 및 렌더링 에러를 발생시키는 특성을 고려, 시스템 다운을 막기 위한 백엔드 내 'avi_path 예외 처리 트리거' 코드를 상시 포함

🎯 7. AI 모델 평가 기준 (Evaluation Metrics) 

**정량적 평가:** 아무 지식이 없는 상태(Scratch)에서 학습을 시작하지 않고, 사람(Person) 특징이 사전에 내장된 COCO pre-trained 가중치(`yolov8n.pt`)를 베이스로 전이 학습(Transfer Learning)을 진행. 
바운딩 박스의 위치 좌표 정확도와 클래스 분류 성능을 동시에 나타내는 핵심 점수인 **mAP50(mean Average Precision @0.5) 스코어 최종 0.85(85%) 이상 달성**을 절대적인 정량 합격 기준으로 설정

**정성적 평가:** 실제 배포 및 구동 테스트 단계에서 학습에 사용되지 않은 외부 신규 영상을 투입, 특히 실제 공사장 CCTV의 거치 환경과 완벽히 매치되는 **부감 각도(Top-down / High-angle)** 및 원거리 소형 객체(Scale 노이즈) 상황에서도 일반인 맨머리(Head)와 안전모(Helmet)를 누락이나 교차 오탐지 없이 깔끔하게 직사각형 바운딩 박스로 추론해내는지 사람이 직접 최종 검증
